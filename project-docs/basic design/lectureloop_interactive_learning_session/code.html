Primary Keys: A candidate key chosen by the database designer. Must uniquely identify each tuple AND must strictly disallow NULL values (Entity Integrity rule).

Common Trip-up: Do not confuse primary keys with candidate keys that allow NULLs or unique constraints that permit a single NULL value.
